# Actividades Hibernate
## Actividad 1: 
Crea un proyecto Hibernate usando Maven
## Actividad 2:
Crea un proyecto Hibernate usando Maven con pool de conexiones
## Actividad 3: 
Crea un programa que solicite los datos para incluir un nuevo aeropuerto
## Actividad 4:
Solicita un id del cliente y devuelve su nombre y sus reservas
## Actividad 5: 
Crea un programa que permita crear, eliminar o actualizar lso datos de un cliente, para ello se ha de mostrar un menú en el se datán 4 opcinoes, las 3 anteriores y salir (hasta que no se seleccione salir deberá volver a este menú cuando se complete la operación). Si el usuario solicita crear se pedirán los datos, si el usuario solicita eliminar se pedirá el id y se mostrarán los datos y la confirmación de la eliminación, si el usuario solicita actualizar se solicitará el id y se solicitará un nuevo nombre para el cliente. Al eliminar un cliente se eliminarán también sus reservas.
## Actividad 6:
Crea un programa que solicite los datos para incliur un nuevo modelo de avión.
## Actividad 7: 
Solicita un id de billete y devuelve los datos del pasajero y los datos del vuelo, incluyendo los aeropuertos de progem y destino.
## Actividad 8:
Crea un programa que solicite un id de reserva y muestre por consola sus pasajeros, una vez mostrada la reserva podrá seleccionar un pasajero a eliminar.
## Actividad 9:
Crea un programa que solicite los datos para incluir un nuevo vuelo. Los aeropuertos de origen y destino y el avión se eligirán de entre los existentes en la base de datos. La duración se calculará a partir de las fechas de salida y llegada, y el estado inicial del vuelo será PROGRAMADO.
