## Actividad 2:

## Actividad 3: 
Crea un programa que solicite los datos para incluir un nuevo aeropuerto
## Actividad 4:
Solicita un id del cliente y devuelve su nombre y sus reservas
## Actividad 5: 
Crea un programa que permita crear, eliminar o actualizar lso datos de un cliente, para ello se ha de mostrar un menú en el se datán 4 opcinoes, las 3 anteriores y salir (hasta que no se seleccione salir deberá volver a este menú cuando se complete la operación). Si el usuario solicita crear se pedirán los datos, si el usuario solicita eliminar se pedirá el id y se mostrarán los datos y la confirmación de la eliminación, si el usuario solicita actualizar se solicitará el id y se solicitará un nuevo nombre para el cliente. Al eliminar un cliente se eliminarán también sus reservas.
## Actividad 6:
