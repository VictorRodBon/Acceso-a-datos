Crear un sistema básico para gestionar el catálogo de una
librería. El ejercicio consiste en diseñar el esquema de 
validación (XSD), el documento de datos (XML) y escribir un 
script (puedes usar el lenguaje que prefieras, por ejemplo, 
Python) que cumpla con los siguientes requisitos:

Validación: Leer el fichero XML y comprobar que cumple 
estrictamente con las reglas definidas en el XSD.

Procesamiento: Recorrer el árbol de elementos XML para extraer 
y mostrar por pantalla:

- El título y el autor de todos los libros cuyo precio sea menor de 15.00€. 
- El número total de libros registrados en la librería.
